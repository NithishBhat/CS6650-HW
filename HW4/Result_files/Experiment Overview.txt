Experiment Overview
I implemented a distributed MapReduce pipeline using AWS ECS (Fargate) and S3. The goal was to split a large text file, map word counts in parallel, and reduce them into a final aggregate JSON file.

Technical Reflections

The biggest pain was managing the Task Definitions and IP addresses.

Image Caching: I ran into a major issue where the "Reducer" was actually running the "Mapper" code because the Task Definition was pointing to the wrong ECR URI.

Task Revisions: Even after pushing new code, I had to manually stop old tasks and create new revisions (Revision 3) to force ECS to pull the updated image.

IP Chasing: Every time a Fargate task restarts, the Public IP changes, requiring constant manual updates to the test URLs.
