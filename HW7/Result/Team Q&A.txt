Part III — Reliability vs Simplicity:

If Payment API goes down for 2 hours, which system is better? Part II (ECS + SQS) — SQS retains messages for 4 days, so all orders survive. Lambda + SNS retries only 2x then discards.

Part III — Operational Burnout:

Complexity: Lambda requires significantly fewer lines of Terraform/code — no SQS queue, no worker service, no Dockerfiles for the worker
Management: No queue depth monitoring needed with Lambda — AWS handles scaling automatically
Is zero ops overhead worth losing SQS reliability? Yes for early-stage startups. No for mission-critical systems where message loss is unacceptable.
